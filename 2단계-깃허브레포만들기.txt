GitHub 저장소 만들기 — 1분

원격 주소는 이미 연결해뒀습니다.
  https://github.com/dbsqja9288/idol-skin-lab.git

BJ님이 하실 일은 GitHub 웹에서 빈 저장소를 만드는 것 하나뿐입니다.

────────────────────────────────────────
1) https://github.com/new  열기

2) 아래 그대로 입력
     Repository name : idol-skin-lab
     Public 선택
     Add a README file          → 체크 해제 (중요)
     Add .gitignore             → None
     Choose a license           → None

   ※ README나 .gitignore를 체크하면 푸시할 때 충돌이 납니다.
     반드시 셋 다 비워둔 채로 만드세요.

3) 초록색 [Create repository] 클릭

4) 이 폴더의 push.bat 더블클릭
     로그인 창이 뜨면 GitHub 계정으로 로그인하세요.
     "DONE. Vercel will redeploy" 가 뜨면 성공입니다.

────────────────────────────────────────
5) 마지막 — 배포

   https://vercel.com/new 열기
   → idol-skin-lab 저장소 Import
   → 프레임워크가 Next.js 로 잡히면 그대로 Deploy

   이후로는 뭔가 바뀔 때마다 push.bat 더블클릭만 하면 됩니다.
────────────────────────────────────────

막히면 화면을 그대로 보여주세요.
